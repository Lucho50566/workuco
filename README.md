# WorkUco · piezas para redes

Rama `redes` del repo de WorkUco. Guarda **solo** las imágenes y videos ya aprobados para publicar en Instagram (@workuco) vía Metricool, que necesita un link público a cada archivo.

- `historias/`: historias 1080 × 1920
- `reels/`: reels 1080 × 1920 y sus portadas
- `publicaciones/`: publicaciones del feed

No va acá nada privado: ni datos de empresas o personas, ni claves.
